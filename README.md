# Playwright E-Commerce Automation Framework

An end-to-end QA Automation Framework built using Playwright and TypeScript following industry-standard automation practices.

## Current Features

- Project Setup
- Login Automation
- HTML Reporting
- Structured Documentation

## Tech Stack

- Playwright
- TypeScript
- Git
- GitHub
